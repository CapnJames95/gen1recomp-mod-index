# Event Distributions

Browse and recreate supported event Pokémon, eggs and island tickets.

For **FireRed and LeafGreen** in gen1recomp (mod API 2). This experimental mod was developed with AI assistance using OpenAI Codex. Back up your saves before use.

**New in 1.3.0:** nine preserved JEREMY gifts, both Wishing Star Jirachi methods, Japanese city OT selection, additional Mt. Battle Ho-Oh languages, Soul Dew for Eon replicas, and corrected Mystic Ticket origins/remaining-counterpart claims. Coverage is 87 campaign menus, 322 choices and 670 variants. Existing USED markers are preserved.

The [mod README](https://github.com/CapnJames95/gen1recomp-mod-releases/blob/main/mods/event-distributor/README.md) explains all additions and known omissions, including disputed JEREMY specimens, insufficiently verified Stamp gifts and journeys requiring RSE maps. PKHeX legality is not proof of historical authenticity.
